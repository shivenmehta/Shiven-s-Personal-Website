Omnidirectional Robot with PID Motion Control

A mecanum-wheel robot designed, fabricated, and programmed to autonomously navigate a maze under time constraints for Science Olympiad.

Overview

As part of my school's Science Olympiad team, my partner and I designed, fabricated, and programmed a robot to navigate a maze under strict time constraints. The challenge required precise autonomous movement, so we built the entire system from scratch: 3D printing the chassis, using stepper motors with mecanum wheel drive for omnidirectional movement, and implementing a PID feedback loop using IMU data for accurate heading correction.

The robot was programmed in C++ using the Arduino IDE. The project achieved top-five finishes out of 50+ teams at both the Stanford Invitational and NorCal Regionals.

Hardware & Design

3D Printed Chassis Custom-designed and 3D printed chassis built to house all electronics and motors in a compact, competition-ready form factor.
Mecanum Wheel Drive Four mecanum wheels driven by stepper motors enable true omnidirectional movement — forward, sideways, and diagonal — without rotating the chassis.
IMU Sensor An MPU6050 IMU provides real-time gyroscope angle data used by the PID controller to detect and correct heading drift during movement.

Version 1 — Stepper Motor Maze Navigation

The first version of the robot used the AccelStepper library to drive four stepper motors with precise step counts, allowing the robot to follow a hardcoded sequence of forward, backward, and rotation commands to navigate the maze. Movement was converted from centimeters to motor steps using the wheel diameter, circumference, and microstepping factor.

A binary search algorithm was implemented to automatically adjust the robot's max speed so that the total path time matched a desired target time — useful for optimizing within the competition's time limit. The robot also monitored battery voltage on startup and indicated low battery via an LED.

Step Calculation Converts cm distances to motor steps using wheel circumference and microstepping factor (4x), with separate step counts per wheel for omnidirectional movement.
Speed Optimization Binary search across speeds to find the accurate speed that completes the full command sequence at the target time.
Command Sequencer A hardcoded 2D string array of {type, value} command pairs (forward, backward, rotate) is executed sequentially, with a button trigger to start the run.

Version 2 — PID Heading Control with DC Motors

The second version replaced stepper motors with DC motors and introduced closed-loop PID control using the MPU6050 IMU for real-time heading correction. Rather than relying purely on step counts, the robot continuously reads its gyroscope angle and applies a proportional-integral-derivative correction to keep it on course during straight movements.

Rotations are handled by a dedicated PID rotation function that spins the robot until the IMU angle matches the target heading within a 2-degree threshold. Motor speeds are dynamically adjusted per side using the correction output, keeping the robot straight even on uneven surfaces.

PID Controller Kp=3.21, Ki=0.0, Kd=0.2 — proportional dominates for fast response, with derivative damping to prevent overshoot near the target angle.
Heading Correction During straight movement, the IMU angle is read every loop iteration and a correction is applied to left/right motor speeds to counteract drift.
Rotation Function rotateUsingPID() runs a closed-loop rotation until the gyroscope angle is within 2 degrees of the target, with integral windup clamped to ±100.

Results

The robot achieved top-five finishes out of 50+ teams at both the Stanford Invitational and NorCal Regionals. The combination of mecanum wheel omnidirectional drive and IMU-based PID correction proved highly effective for precise autonomous maze navigation under competition time pressure.
