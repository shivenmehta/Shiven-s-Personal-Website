Digital Combinational Lock (Discovery Project)

A harware-based combinational logic that was designed and put together by pure electronic circuit elements and discrete logic-based ICs

Overview

After taking ECE 2020, Georgia Tech's Digital System Design class during my first semester as a college student, I was amazed by how fundamental digital design is to everything, from consumer electronics to modern computing. Thus, I wanted to extend the concepts I had learned in the class by applying applying both combinational and sequential logic to build a real working combination lock from discrete logic ICs. I thought it was a challenging, but manageable project that used the theory covered in class and expanded it to the next level. While the actual circuit is a work in progress, I have successfully implemented the core memory management and display elements, which I will walk through below.

This project also introduced me to unexpected challenges that I never would have encountered if I never tried to put my theory into practice. These issues spanned from signal debouncing, power and current management, and most important, circuit organization.

Circuit Design Plan

Input Memory Management Converts decimal keypad input into binary and manages input storage for both display selection and password handling.
Display Selection Handles clock control logic, circuit timing, and 7-segment decoder/display logic to accurately render user input on screen.
Password Memory Management Manages password storage with support for a new password button, a reset option for unset passwords, and comparator logic for password verification.
System/State Control A Finite State Machine governs when a password can be accepted and clocked into memory, along with reset handling for cases where no password has been set.

Materials list for the Digital ICs and Circuit Elements needed for this project

  • 12-13 Push Buttons
  • 1 x 10-to-4 Priority Encoder
  • 2 x Hex Inverter ICs
  • 1 x 4-bit D Latch
  • 1 x JK Flip-Flop
  • 5 x 4-bit Flip-Flops
  • 2 x 7-Segment Decoders
  • 2 x 7-Segment Displays
  • 1 x 8-bit Comparator
  • 2-3 x OR Gate ICs
  • 2-3 x AND Gate ICs
  • Diodes (a lot)
  • Wires (as needed)
  • Resistors (as needed)
